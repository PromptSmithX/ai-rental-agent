# AGENTS.md addendum — data ingestion phase

Read `docs/ingestion/` and `prompts/IMPLEMENT-INGESTION.md` before editing ingestion code. For the scope of this phase, implementing FastAPI-side ingestion and DB migrations is explicitly allowed; AI/LLM/agent implementation is not. Keep changes isolated to ingestion, persistence and tests; treat frontend contracts as stable. Request clarification for unknown copyright/image redisplay rights; default to no image downloads if not explicitly covered. Preserve raw unmodified prices, descriptions and conflicting fields. Use permission-first collection, Hanoi filter, resumability, snapshots, and run audit. Avoid capturing personal phone/name data. Do not claim that scraped listings are verified/available. Do not use scraped raw tables directly as AI search truth.
